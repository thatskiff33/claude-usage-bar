# claude-usage-bar
5 hourly and weekly usage limits shown in Claude Code CLI for easy visibility

## Install

```sh
claude plugin marketplace add thatskiff33/claude-usage-bar
claude plugin install usage-bar@claude-usage-bar
```

Or from inside Claude Code:

```
/plugin marketplace add thatskiff33/claude-usage-bar
/plugin install usage-bar@claude-usage-bar
```

To also show the weekly (7-day) limit, run `/plugin configure usage-bar@claude-usage-bar` and turn on **Show weekly usage**.
